# Luni's Basic Business Administration System

## PROBLEMA A RESOLVER
	Una empresa (cualquiera) requiere un sistema de gestión que, cómo mínimo, sea capaz de: 
		- Crear, administrar y buscar archivos relevantes a la empresa (compras de la empresa / ventas de la empresa, recibos de sueldo y documentos generales relativos a la empresa)
		- Administrar eventos en un calendario, sean cada 30 minutos, semanales, todos los dias a una hora ó todos los martes y jueves si fuese necesario
		- Mantener una agenda bien ordenada general para la empresa y para cada director y administrador de la empresa, así como permitir buscar, buscar por usuario registrado, por etiquetas, pseudónimos, etc.
		- Mantener un stock de productos y servicios
